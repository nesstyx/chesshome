# Трансляции (lichess broadcasts) — ChessHome

Страница `/broadcasts` — список ТУРНИРОВ, `/broadcasts/t/<id>` — страница
турнира со списком его партий, `/broadcasts/<id>` — партия на весь экран с
обновлением в реальном времени. Сервер сам НЕ ходит в lichess (исходящих
запросов у него нет): ходы подтягивает скрипт на твоём ПК.

Структура: Турнир (например «FIDE World Championship 2026») → внутри него
партии (раунды lichess). Удаляешь турнир — удаляются и его партии
(каскадом, вместе с PGN и чатом). Партии, созданные до появления турниров,
показываются на главной в секции «Партии без турнира» — их можно перенести
в турнир со страницы турнира.

Ходы применяются у зрителей АВТОМАТИЧЕСКИ, без кнопки «есть новые ходы»:
кнопка остаётся только для случая, когда зритель ушёл в свой локальный
вариант (двигал фигуры) — тогда трансляция его доску не трогает до клика.

## Как это работает

```
[lichess.org] --(PGN, опрос раз в 2.5 c)--> [broadcast-pusher.js на твоём ПК]
      --> [POST /api/broadcasts/push с ключом] --> [PostgreSQL ChessHome]
      <-- [поллинг /api/broadcasts/<id> раз в 2 c] <-- [браузеры зрителей]
```

## Файлы

**Новые:**
- `server/routes/broadcasts.js` — роуты и таблицы (создаются сами при старте)
- `public/broadcasts.html` — список турниров + форма «Новый турнир» для админов
- `public/broadcast-tournament.html` — страница турнира: список партий,
  формы «Добавить партию» и «Перенести партию» для админов
- `public/broadcast.html` — страница партии (доска, часы, ходы, LIVE)
- `scripts/broadcast-pusher.js` — мост Lichess→сервер, запускать на ПК

**Изменённые:**
- `server/routes/index.js` — добавлена строка `require('./broadcasts')(app);`
- `server/env.example` — добавлен `BROADCAST_PUSH_KEY=`

## Установка на сервере

1. Скопируй файлы в репозиторий.
2. Добавь в `.env` сервера (придумай длинный случайный ключ):

```env
BROADCAST_PUSH_KEY=длинный_случайный_ключ
```

3. Перезапусти сервер (`npm start`). Таблицы создадутся автоматически,
   миграция запускается не нужна.

## Создание трансляции

1. Зайди на `/broadcasts` под админом (роль admin) — появится форма
   «Новый турнир»:

- Название — например `FIDE World Chess Championship 2026`
- Дата и время начала
- Описание — например `Матч на звание чемпиона мира`

После создания откроется страница турнира `/broadcasts/t/<id>`.

2. На странице турнира — форма «Добавить партию в турнир»:

- Название партии — например `Game 1 — Gukesh D — Sindarov`
- Дата и время начала — локальное время
- Ссылка на раунд Lichess — та самая:
  `https://lichess.org/broadcast/fide-world-chess-championship-2026/game-1/xLgOJ6cb`
  (ID раунда `xLgOJ6cb` вытащится из ссылки автоматически)
- Описание — например `GM Gukesh D — GM Sindarov, Javokhir`

Старые партии (созданные до обновления) переносятся в турнир на его
странице формой «Перенести партию в этот турнир».

## Запуск моста на ПК

Node >= 18, зависимостей не нужно:

```bash
node scripts/broadcast-pusher.js \
  --lichess "https://lichess.org/broadcast/fide-world-chess-championship-2026/game-1/xLgOJ6cb" \
  --site https://chesshome.pro \
  --key БРОАДКАСТ_КЛЮЧ_ИЗ_ENV
```

Скрипт опрашивает `https://lichess.org/api/broadcast/round/<id>.pgn?clocks=true&evals=true`
и отправляет PGN на сервер только когда он изменился. При ошибках — бэкофф,
при неверном ключе — сразу выход с понятной ошибкой. Раунд в lichess
заканчивается — просто запусти скрипт со ссылкой на следующий раунд.

Остановка: Ctrl+C.

## Эндпоинты API

| Метод | Путь | Кто |
|---|---|---|
| GET | `/api/broadcast-tournaments` | список турниров (статус сводится из статусов партий) |
| POST | `/api/broadcast-tournaments` | создать турнир — только admin (сессионная кука) |
| POST | `/api/broadcast-tournaments/:id/delete` | удалить турнир ВМЕСТЕ с партиями — только admin |
| GET | `/api/broadcasts` | список партий (?tournament=<id> — только партии турнира) |
| GET | `/api/broadcasts/:id` | детали + свежий PGN (поллинг страницы партии) |
| POST | `/api/broadcasts` | создать партию (опц. `tournamentId`) — только admin (сессионная кука) |
| POST | `/api/broadcasts/:id/set-tournament` | привязать/перенести/отвязать партию к турниру — только admin |
| POST | `/api/broadcasts/:id/delete` | удалить партию — только admin |
| POST | `/api/broadcasts/push` | приём PGN от скрипта на ПК, ключ в заголовке `x-broadcast-key` |

Статусы партии: `upcoming` (есть время начала, партии нет) → `live`
(PGN обновляется) / `paused` (нет обновлений >15 мин) → `finished` (есть
результат в PGN). Статус турнира — сводный по его партиям: есть live →
`live`; все finished → `finished`; есть upcoming → `upcoming` и т.д.

## Нюансы

- Статика `/broadcasts.html`, `/broadcast-tournament.html` и
  `/broadcast/<id>` отдаётся и напрямую, и через красивые пути
  `/broadcasts`, `/broadcasts/t/<id>`, `/broadcasts/<id>`.
- Если в раунде несколько партий (многобоевые турниры) — над доской появится
  селектор партий, каждая партия со своим списком ходов и часами.
- Часы и дебют берутся из PGN Lichess (`[%clk ...]`, тег `Opening`).
- Ссылку «Трансляции» в шапку сайта добавь в нужные страницы
  (`<li><a href="/broadcasts">📡 Трансляции</a></li>`).
- Таблицы и колонка `broadcasts.tournament_id` создаются/добавляются
  автоматически при старте сервера (ALTER … ADD COLUMN IF NOT EXISTS),
  миграция запускается не нужна.
